# ✦ Orbit Monochrome OS — GDG NSUT

> A sleek, high-performance community recruitment and discovery portal built for **Google Developer Groups (GDG) NSUT**.

---

📌 Overview

Orbit Monochrome OS is a streamlined web dashboard designed to simplify community discovery, track open positions, and manage application pipelines for GDG NSUT teams and initiatives. Built with a modern, high-contrast monochrome aesthetic, it provides an intuitive interface for students to explore tech, design, and product tracks.

---

✨ Features

* Live Search & Track Filtering: Instantly filter communities and open positions by category (Technology, Design,Culture) or via real-time keyword search.
* Shortlist & Bookmark System: Save interested teams to a interactive watchlist with dynamic statistics updating on the fly.
* Modal-Based Application Flow: Direct interactive modal popups for viewing full role descriptions and submitting applications directly.
* Application Tracker: Live view of all active submissions and status updates within the session.
* Zero External JS Dependencies: Pure Vanilla JavaScript, HTML5, and CSS3 for maximum performance and lightning-fast load times.

---

🛠️ Tech Stack

* Frontend: HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
